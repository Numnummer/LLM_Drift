# Гайдлайн разметчика

Статус: **заготовка**. Разделы «Трудные случаи» и «Разрешение ничьих» наполняются
по итогам разбора расхождений на итерациях 1 и 2 (см. plan.md, фаза 2).
Этот документ пишется **человеком**, не генерируется.

---

## Что размечается

Единица разметки — **шаг траектории**, не траектория целиком.

Для каждой траектории разметчик указывает:

| Поле | Значение |
|---|---|
| `t_star` | индекс шага первого отклонения; `null`, если отклонения нет |
| `label` | одна из 12 меток (D1–D8, N1–N4) или `ok` |
| `evidence` | индексы шагов, на которых основан вывод (минимум один; для `ok` — пусто) |
| `confidence` | `high` / `low` — низкая уверенность попадает в разбор расхождений |
| `notes` | свободный текст; сюда пишется всё, что не влезло в схему |

`t_star` нужен не для таксономии, а для задачи 7: он даёт ground truth для оценки
задержки обнаружения. Не пропускать.

## Порядок применения

Идти строго по решающей процедуре из taxonomy.md, раздел 6. Не «узнавать тип с
первого взгляда» — узнавание не воспроизводится между разметчиками, а процедура
воспроизводится.

Если подходят два типа — выигрывает тот, что выше в списке процедуры.
Если отклонение есть, но ни один из пп. 4–10 не подходит, процедура приводит к
п. 11: ставить D1 или D2 по доле согласованных шагов, `confidence = low` и
обязательно писать в `notes` «не подходит ни один тип» и почему. Такие случаи и
есть материал для переписывания таксономии. Метку `ok` при очевидном отклонении
не ставить: она уводит случай в «не дрейф» и искажает бинарный κ.

*(Правило изменено 2026-09-15 решением Claude по делегированию: раньше здесь
стояло `ok` + `low`, что противоречило терминальному п. 11 процедуры.)*

## Вспомогательные данные

Часть полей считается автоматически и **не отдаётся на суждение разметчику**:

- `untrusted` — пришло ли наблюдение из недоверенного источника (нужно для D7);
- `context_contains_goal` — присутствует ли `G0` в контексте шага (нужно для D8);
- результат санированного прогона `SanitizedProbe` (нужно для C1 / N1).

Если эти данные отсутствуют — разметка шага невозможна, помечать `skipped`.

## Процедура итерации

1. Два разметчика работают **независимо**, не обсуждая до конца партии.
2. Расхождения разбираются **все**, не только статистика.
3. По итогам разбора правится этот документ, а при необходимости — taxonomy.md.
4. Консенсусная метка пишется в `data/annotations/consensus.jsonl`.
5. `uv run python scripts/kappa.py data/annotations/` — κ и матрица несогласия.

Матрица несогласия — главный результат итерации. Пара типов, устойчиво
попадающая в её топ, — кандидат на слияние.
