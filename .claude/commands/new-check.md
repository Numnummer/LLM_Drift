Добавь или реализуй проверку для типа дрейфа $ARGUMENTS.

1. Прочитай определение типа в @docs/taxonomy.md: формальный признак, ближайшего
   соседа и позицию в решающей процедуре (раздел 6).
2. Реализуй функцию в src/taxonomy/checks.py по сигнатуре
   Check = Callable[[Trajectory, Judge, SanitizedProbe, Thresholds], Verdict | None].
   Возврат None означает «тип не подтверждён, идём дальше по дереву».
3. Verdict обязан содержать evidence — индексы шагов, на которых основан вывод,
   и rationale человекочитаемой строкой. Вердикт без evidence не принимается.
4. Все пороги брать из Thresholds, не хардкодить числа в теле проверки.
5. Обращения к LLM — только через протокол Judge. Прямых вызовов API в checks.py быть не должно.
6. Позиция в CHECKS берётся из решающей процедуры, НЕ из конца списка.
   Если кажется, что порядок надо поменять — остановись и спроси.
7. Добавь в tests/test_checks.py минимум два кейса: положительный и граничный
   с ближайшим соседом из taxonomy.md.
8. Прогони `uv run pytest` и покажи результат.

Если формальный признак в документе недостаточен для реализации — не додумывай:
выпиши, чего именно не хватает, и спроси.
